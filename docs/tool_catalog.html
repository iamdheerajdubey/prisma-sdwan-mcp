Tool Reference

An AI can read your Prisma SD-WAN fabric. It cannot change it.

What this is

A translation layer. The AI speaks in operator intent — “is BGP up at the Pune branch?” — and this server turns that into the right controller API calls, resolves the site and device names into IDs, strips secrets out of the response, and hands back a bounded answer.

Without it, an AI would need to know 316 endpoint names, their path parameters, and your tenant's internal object IDs. With it, the AI needs to know 26 tools.

Is it what you need

The honest boundary, before you read the tool list.

Built for this

  • Asking questions about live network state in plain language
  • Troubleshooting — correlating routing, WAN, events, and topology across tools
  • Auditing configuration and policy without opening the GUI
  • Letting a non-expert get answers without learning the API
  • Drafting site configuration as YAML for Ansible to apply

Not built for this

  • Changing anything on the controller — no create, update, or delete exists
  • Pushing config. generate_site_config writes a local file; your change process applies it
  • Bulk export or reporting — responses are capped to protect the conversation
  • Real-time streaming or alerting; it answers when asked, nothing runs on a timer
  • Anything outside Prisma SD-WAN and its SASE/ADEM integration points

The read-only guarantee is structural, not a policy someone can toggle. The action catalog this server executes from contains only GET and POST-query endpoints. No write endpoint is described anywhere in it, so no tool can invoke one.

Limits & safety

PropertyBehaviour
MutationStructurally impossible. The catalog holds 202 GET and 106 POST actions; every POST is a query that needs a request body. No create, update, or delete endpoint is described anywhere.
SecretsEvery response is walked recursively and sensitive keys are redacted before the AI ever sees them.
Response sizeCapped and paginated, so one broad question cannot flood the conversation.
AmbiguityTwo sites matching one name returns both as candidates. The server never picks for you.
Fan-outTools that loop over peers or interfaces stop at a configured ceiling and say so in the response.
Expert toolread_capability can be disabled entirely, reducing the surface to the 24 direct tools.
Unverified actions8 hand-added catalog entries refuse generic execution until validated against a live tenant.
AuthenticationLazy login, automatic re-auth on 401/403, bounded backoff on 429 and 5xx.
